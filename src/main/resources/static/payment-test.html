SPARTA SHOP 결제창 테스트
사용 순서
  1. 주문 생성 또는 테스트 SQL로 Payment READY 데이터를 준비합니다.
  2. 아래에 서버가 생성한 portonePaymentId와 PG 결제 금액을 입력합니다.
  3. 결제 완료 후 같은 portonePaymentId로 POST /api/payments/confirm을 호출합니다.
1
주문 결제 정보 입력 필수 입력
서버 DB에 저장된 portonePaymentId와 동일해야 결제 확정 검증을 통과합니다.
Payment.pgAmount와 동일한 금액을 입력하세요.
2
결제자 정보 기본값 사용 가능
결제 완료: PortOne 콜백을 받았습니다
portonePaymentId: 결제 확정 API에 사용
-
위 portonePaymentId를 사용해서 POST /api/payments/confirm을 호출하세요.
